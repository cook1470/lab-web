# 掛機港灣（idle-cove）驗收判準

**要驗的一件事**：關掉分頁、放著不管、上班中偶爾瞄一眼——港灣自己從冷清變熱鬧，回來一眼看得出「現在比剛才熱鬧」。這是唯一要驗的事，不驗好不好玩、不驗機制深不深。

**怎樣算沒過**（任一項成立就算沒過）：

1. `skip(0)` / `skip(600)` / 累計到 `skip(3600)` / 累計到 `skip(28800)` 四張截圖，冷眼快速掃過去分不出熱鬧程度差別（房子數、人數、船、燈光看起來都差不多）。
2. 8 小時那張畫面糊成一團看不清——sprite 疊太多、看不出建築輪廓、或看不出哪裡是房子哪裡是人。
3. 重新整理頁面（模擬換分頁回來）之後，沒有出現「你不在的時候」離線收益畫面；或者畫面上顯示的數字/棟數，跟 `__idle.state` 實際狀態對不上。
4. 遊戲載入時預設不是靜音；或使用者沒按喇叭圖示，聲音卻自己響了一次以上。
5. 畫面上出現大彈窗、閃爍效果、或任何會讓人一眼被「抓住注意力」的搶眼動畫——不符合「上班掛機，被同事瞄到不突兀」的前提。
6. 過程中出現任何 JS console error。
7. 完全不點任何東西，經過 8 小時模擬後遊戲卡住不動（例如空地永遠蓋不出房子、船永遠不消失擋在畫面正中間、離線面板點不掉）。

**怎樣算過**：四張截圖用肉眼掃過去，能立刻分出「哪張比較熱鬧」且順序正確（0 < 10分 < 1小時 < 8小時，且 8 小時是明顯「已經很熱鬧」的滿足感，不是還很空）；離線面板數字與 `__idle.state` 吻合；全程無 console error；不點也不會卡死。
