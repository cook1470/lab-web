## 2. 離線收益（模擬「離開一小時」）

用兩個分頁測：分頁一寫入偽造存檔 `{elapsed:500, lastTs: now-3600s}` 後關掉；分頁二重新整理載入，讀到偽造存檔。

- 讀到後 `elapsed=4100.0`（500+3600，正確），`housesBuilt=8`（跟純函式算出的 `housesBuiltCount(4100)=8` 一致）。
- 離線面板正確跳出（`offlinePanel:true`），面板數字：`+3`（房子，8-5=3）、`+7`（人口，20-13=7）、`+23`（船，一致於 `floor(3600 / lerp(180,45,prosperity(500)))`）——跟 `__idle.state` 算出來的 delta 完全對得上。
- 點畫面中央任意處，面板消失（`offlinePanel:false`），底下的城鎮畫面正確露出。
- 靜音狀態維持 `muted:true`（偽造存檔裡帶的值），沒有自動出聲。
- console error：0。

## 3. 互動（點擊）

- 點正在閃的空地：立刻蓋好（`elapsed` 從 0.3s 跳到 90.2s，房子數 2→3），沒點的話會在 90 秒後自動蓋好——不點不會壞，只是慢。
- 點喇叭圖示：`muted` 從 `true` 變 `false`，正常運作。
- console error：0。

## 4. 對照 CRITERIA.md 七條沒過的條件

1. 四張截圖看得出差別——過。
2. 8 小時沒有糊成一團——過。
3. 重新整理後離線面板正確出現、數字吻合——過。
4. 預設靜音、沒點喇叭不會自己出聲——過（用的是 WebAudio，且需要使用者手勢才建立 AudioContext，理論上瀏覽器層面也擋得住自動出聲）。
5. 沒有大彈窗／全螢幕閃爍——過。離線面板本身是一個置中的小長方形，不是滿版彈窗；空地/待升級的提示是小範圍的緩慢閃爍（約 1.5 次/秒），不是全螢幕效果。
6. 全程 0 個 console error——過。
7. 完全不點，8 小時後畫面正常運作、船會自己離開、空地會自己蓋滿——過（skip 測試全程沒有任何點擊介入）。

## 已知局限（誠實列，沒有藏起來）

- 海面的動態光影用「整欄同色」畫，遠看是垂直條紋而不是水波紋——能看但不是很精緻，是為了控制範圍先做出可判斷的東西。
- 8 小時後遊戲進度即封頂（房子全滿級、人口封頂 30），之後只剩下偶爾的星星閃爍與船隻進出當作「持續熱鬧」的訊號，沒有再往上長的空間——如果要交給 Cook 判斷「值不值得做」，這點要老實講清楚：這是一個「一天內走完」的節奏，不是能無限掛機下去的節奏。
