# folk-c：救不救

你不能控制任何人。只有出事的那一刻（被樹壓住／淋雨生病／餓倒），那個人頭上會出現一個閃爍的手掌圖示，下方的黃條是剩餘時間。8 秒內點它，就會有一隻大手從天上伸下來救他：樹被抬走且不受傷／病立刻好／立刻吃飽。

代價：每救一次，倉庫少 2 份食物（不夠就讓田裡熟的作物枯掉補足）。更重的是：同一個人被救過 2 次，就認定「反正會有人救我」，從此不工作、窩在營火邊（頭上一圈金色光圈），被別人看到吃倉庫會被記恨、找去打架，也少一個人產糧。挑著救（每人最多救一次）就不會有這個後果。
不救的話，通常會有別人去救（兩人感情變好、冒愛心），或他自己撐過去（拄拐杖）、甚至餓死。

## 程式操作
```js
FOLK_ACT('save')             // 救目前最早的那個待救事件
FOLK_ACT('save', id)         // 救指定小人（他必須正在 8 秒視窗內）
FOLK_ACT('policy', 'always') // 之後每次出事都立刻救（量測用）
FOLK_ACT('policy', 'never')  // 都不救（等同不碰）
FOLK_ACT('at', 秒, ...上面任一種) // 在模擬時間到了才執行
```
出事的時間點由模擬決定，所以固定腳本建議用 policy。玩家操作寫進 `FOLK_LOG`，例如 `玩家：伸手救被樹壓住的草帽紅衣（倉庫少了 2 份）`。

## 固定腳本範例
```js
FOLK_ACT('at', 0, 'policy', 'always');
```
