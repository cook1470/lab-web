# folk-b：天氣

操作：左下角三個圖示按鈕——雲＝下雨、太陽＝放晴、麥穗＝豐收。按過之後按鈕被暗色蓋住，暗色由上往下退，表示冷卻中。

代價：
- 下雨（冷卻 25 秒）：下 22 秒雨，作物長得快；在外面的人會淋濕生病、營火熄滅。
- 放晴（冷卻 20 秒）：雨立刻停，接著乾旱 40 秒（畫面偏黃、田地裂開），作物幾乎不長，也不會自然下雨。一直按放晴＝一直乾旱＝會缺糧餓倒。
- 豐收（冷卻 70 秒）：整片田立刻成熟，之後田地休耕 70 秒（田上蓋一層灰）完全不長。

## 程式操作
```js
FOLK_ACT('rain' | 'sun' | 'bless')      // 馬上執行（冷卻中會被忽略）
FOLK_ACT('at', 秒, 'rain' | 'sun' | 'bless') // 在模擬時間到了才執行
```
玩家操作會寫進 `FOLK_LOG`（`玩家：下雨`／`玩家：放晴（接下來乾旱）`／`玩家：豐收（之後田地休耕）`），`乾旱結束`、`田地休耕結束` 也會記。

## 固定腳本範例
```js
[['at',20,'bless'], ['at',45,'rain'], ['at',90,'sun'], ['at',140,'rain']].forEach(a => FOLK_ACT(...a));
```
