# folk-a：分工

操作：點一個小人（腳下出現閃爍框，四個可去的地方會亮框）→ 點地方：
右上樹林＝砍樹、田＝種田、營火＝顧火、房子＝休息。再點一次同一個小人＝取消指派（回到自己決定）。
被指派的人腳邊有小圖示（斧頭／芽／火／枕頭）；對照組 `?plain=1` 不畫。

代價：
- 砍樹：每砍倒一棵有 25% 被樹壓住；下雨也不收工，容易生病。
- 種田：下雨也不收工，容易生病。
- 顧火：有人在火邊時，雨中營火不熄、火邊的人不會淋濕；但他不生產食物。
- 休息：在別人眼裡就是懶人，被看到吃倉庫的東西會被記恨、最後被找去打架。把懶人派去工作，他就不算懶人。

## 程式操作
```js
FOLK_ACT('assign', id, job)          // 馬上執行（下一步生效）
FOLK_ACT('at', 秒, 'assign', id, job) // 在模擬時間到了才執行（量測請用這個，跟 fast 無關）
// job: 'chop' | 'farm' | 'fire' | 'rest' | 'free'
// id: 0 草帽紅衣 1 橘刺髮藍衣 2 青衣小孩 3 白鬍子綠衣老人 4 金長髮紫裙 5 紅頭巾白衣
```
玩家操作會寫進 `FOLK_LOG`，例如 `{t:5, who:[0], what:'玩家：叫草帽紅衣去砍樹'}`。

## 固定腳本範例（載入頁面後立刻呼叫）
```js
[['at',5,'assign',0,'chop'], ['at',5,'assign',1,'chop'],
 ['at',20,'assign',2,'rest'], ['at',60,'assign',3,'fire']].forEach(a => FOLK_ACT(...a));
```
